# 모의고사 변환·출제 스킬

## 이 스킬이 하는 일

입력이 두 갈래지만 출력은 하나다.

```
평가원 PDF ─┐
            ├─> exam.json (중간 표현) ─> 한글 시험지(.hwpx)
교사의 출제 ─┘
```

도구는 저장소의 `mogosa/` 패키지다. 작업 디렉터리는 저장소 루트로 잡는다.

## 준비

```bash
pip install python-hwpx pdfplumber
```

---

## 갈래 1: PDF를 한글 파일로 변환

```bash
python -m mogosa pdf2hwpx 기출.pdf -o 기출.hwpx --subject "생활과 윤리" --json 기출.json
```

변환 후 **반드시 경고를 확인하고 사용자에게 그대로 전달한다.** "선택지를 3개만
찾음" 같은 경고는 조판이 틀어졌다는 뜻이므로 숨기지 않는다.

손볼 곳이 있으면 `pdf2json`으로 JSON을 뽑아 고친 뒤 `json2hwpx`로 조판한다.

```bash
python -m mogosa pdf2json 기출.pdf -o 기출.json
# (JSON 수정)
python -m mogosa json2hwpx 기출.json -o 기출.hwpx
```

## 갈래 2: 교사의 요청으로 문항 출제

### 1단계 — 필요한 것을 확인한다

이미 주어진 것은 다시 묻지 않는다. 비어 있는 것만 묻는다.

- 과목 (생활과 윤리 / 윤리와 사상 / 그 밖)
- 단원 또는 성취기준 (예: `[12현윤05-01]`)
- 지문·제시문 (교사가 준 것을 쓸지, 새로 쓸지)
- 문항 수, 3점 문항 수

지문이 이미 제시됐고 문항 수만 말했다면 그대로 진행한다.

### 2단계 — 평가원 문항 작법을 지킨다

**발문 유형** — 아래에서 고른다. 임의로 지어내지 않는다.

| 유형 | 발문 |
|---|---|
| 입장 파악 | 다음 사상가의 입장으로 가장 적절한 것은? |
| 부정 발문 | 다음 입장에서 부정의 대답을 할 질문으로 가장 적절한 것은? |
| 비교 | 갑, 을의 입장에 대한 설명으로 옳은 것만을 \<보기\>에서 있는 대로 고른 것은? |
| 반론 | 갑의 입장에서 을에게 제기할 반론으로 가장 적절한 것은? |
| 공통점 | 갑, 을이 모두 긍정할 진술로 가장 적절한 것은? |

**선택지 규칙**

- 반드시 5개. 길이를 서로 비슷하게 맞춘다.
- 오답은 "틀린 말"이 아니라 **다른 사상가의 옳은 주장**이어야 한다. 그래야 변별력이 생긴다.
- 정답 번호를 1~5번에 고루 분산시킨다. 한 시험지에서 같은 번호가 몰리지 않게 한다.

**\<보기\> 문항**

- 항목은 ㄱ, ㄴ, ㄷ (필요하면 ㄹ까지).
- 선택지는 조합형으로 쓴다: `ㄱ`, `ㄷ`, `ㄱ, ㄴ`, `ㄴ, ㄷ`, `ㄱ, ㄴ, ㄷ` 같은 식.
- 조합 선택지는 짧으므로 렌더러가 알아서 한 줄에 배치한다.

**배점** — 3점 문항만 `points: 3`으로 표기한다. 2점 문항은 `null`로 두는 것이 평가원 관례다.

### 3단계 — JSON을 쓴다

`mogosa/examples/sample_exam.json`을 본보기로 삼는다. 구조는 아래와 같다.

```json
{
  "subject": "생활과 윤리",
  "area": "사회탐구 영역",
  "title": "2026학년도 1학기 기말고사 대비 모의고사",
  "form": "홀수형",
  "questions": [
    {
      "number": 1,
      "stem": "다음 사상가의 입장으로 가장 적절한 것은?",
      "points": 3,
      "passage": ["상자 없이 들어가는 지문. 없으면 빈 배열."],
      "boxes": [
        { "kind": "제시문", "lines": ["갑: ...", "을: ..."] },
        { "kind": "보기", "auto_mark": true, "lines": ["첫째 항목", "둘째 항목"] }
      ],
      "choices": ["①에 들어갈 말", "②", "③", "④", "⑤"],
      "answer": 3,
      "explanation": "정답 근거와 오답 이유.",
      "tags": ["환경 윤리", "12현윤05-01"]
    }
  ]
}
```

주의할 점

- `choices`에 `①` 같은 기호를 **직접 넣지 않는다.** 렌더러가 붙인다.
- `boxes[].auto_mark`가 `true`면 `ㄱ. ㄴ. ㄷ.`이 자동으로 붙는다. 항목에 직접 `ㄱ.`을 써 놓았다면 `false`로 둔다.
- `answer`와 `explanation`은 시험지 본문에는 찍히지 않는다. `--answers`를 줄 때만 뒤에 붙는다.

### 4단계 — 조판한다

학생 배부용과 교사용을 따로 뽑아 주는 것이 좋다.

```bash
python -m mogosa json2hwpx 출제.json -o 시험지.hwpx              # 학생용
python -m mogosa json2hwpx 출제.json -o 시험지_정답.hwpx --answers  # 교사용
```

### 5단계 — 결과를 알린다

- 만든 파일 경로
- 정답 분포 (예: ③②⑤①④)
- 검증 경고가 있으면 그대로 전달

## 서식 바꾸기

`--columns 1` (1단), `--font "바탕"`, `--size 11` 로 조정한다. 더 세밀하게는
`mogosa/hwpx_writer.py`의 `Style` 데이터클래스를 고친다. 여백·줄간격·문항
간격·내어쓰기 폭이 전부 거기 모여 있다.

## 한계 — 사용자에게 숨기지 말 것

- 결과물은 `.hwpx`다. 구형 `.hwp`가 필요하면 한글에서 열어 *다른 이름으로
  저장*하면 된다.
- PDF 변환은 레이아웃 추론이라 100%가 아니다. 표·그래프·그림이 들어간 문항은
  글자만 넘어오고 그림은 빠진다. 사회탐구 지문형 문항은 잘 되지만, 도표
  자료가 많은 문항은 손봐야 한다.
- 스캔한 PDF(이미지)는 글자가 없어서 변환되지 않는다. OCR이 먼저 필요하다.
